v2beta3 Feature Two Queue fields that in previous versions were output only are now configurable. taskTtl is the maximum amount of time that a task is retained in this queue. tombstoneTtl is the amount of time the task tombstone is retained after a task is deleted or executed. The tombstone is used in task de-duplication. For more information on this process, see Create Task Request . These fields are also available in v2beta2.
