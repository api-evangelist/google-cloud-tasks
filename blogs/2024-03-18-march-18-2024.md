v2 Announcement For tasks that have HTTP targets (as opposed to App Engine targets), the option to set routing for tasks at the queue level is now at General Availability (GA). If you set routing at the queue level, you do not have to set routing for each individual task. To learn more, see Configure routing . Announcement The BufferTask method for creating tasks is now at General Availability (GA).
